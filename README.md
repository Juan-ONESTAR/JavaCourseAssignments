# Java Course Assignments

This repository contains my Java programming assignments for this course.

Each assignment is stored in its own folder. Every assignment folder contains its Java source files, any required text data files, and an assignment-specific README.

## Repository Structure

```text
JavaCourseAssignments/
├── README.md
├── .gitignore
├── .gitattributes
├── SETUP.md
├── templates/
│   └── assignment-readme-template.md
└── week-08-assignment-05/
    ├── README.md
    ├── src/
    └── data/
```

## Folder Organization

Each assignment folder uses the following structure:

- `src/` — Java source files
- `data/` — Text files or other input data
- `README.md` — Assignment description, OnlineGDB link, file list, and run instructions

## General Running Instructions

Open the folder for the assignment you want to run and follow the instructions in that assignment's README.

## Naming Convention

Assignment folders use lowercase letters and hyphens:

```text
week-08-assignment-05
week-09-assignment-06
week-10-final-project
```

Java file names must match their public class names exactly.

Example:

```java
public class FutureContract
```

must be saved as:

```text
FutureContract.java
```
