# Week 8 Assignment 5 — Exception Handling, Interfaces and More

## Assignment Description

This assignment extends the futures contract project by introducing exception handling, interfaces, file input, collections, and volatility computation.

The program reads historical price information from a text file, stores the data in a collection, and uses the assignment's required classes and interfaces to process the price information.

- Inheritance
- Exception handling
- `BufferedReader`
- `FileReader`
- `IOException`
- `ArrayList`
- Java collections
- File input
- Iteration through price data
- Monte Carlo volatility computation

## How to Run the Program

### Option 1: Run with an IDE

1. Download or clone this repository.
2. Open the `week-08-assignment-05` folder in a Java IDE.
3. Make sure all `.java` files in `src/` are included in the project.
4. Make sure the required text data files are available at the paths expected by the program.
5. Run the class containing the `main` method.

### Option 2: Run from the Command Line

From inside the `week-08-assignment-05` folder, compile the Java files:

```bash
javac -d out src/*.java
```

Run the class containing the `main` method:

```bash
java -cp out Main
```

If the class containing `main` is not named `Main`, replace `Main` with the correct class name.
